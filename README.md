A small neural network built with plain Python and NumPy, no deep learning frameworks. The goal of this project is to understand how forward passes, backpropagation and training work under the hood.

Getting started
bash
  pip install numpy
  python layers.py
Machine_learning is pretty unnecessary so no need to use it
R  unning layers.py executes the gradient check. If the output says the backprop is correct, the layers work as expected.
